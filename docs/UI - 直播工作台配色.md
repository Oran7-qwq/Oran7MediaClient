# 直播工作台配色

## 当前深色方案：石墨与雾蓝

本轮仅调整深色工作台的颜色，不改变布局、材质、背景视差或业务行为。浅色模式尚未实施独立配色。

| 角色 | 颜色 | 使用范围 |
| --- | --- | --- |
| 底色 | `#11161D` | 工作台底板 |
| 面板 | `#1E252F` | 四个分区 |
| 分组 | `#242D39` | 设置组与混音通道底板 |
| 输入槽 | `#161E29` | 输入、选择器 |
| 悬停 | `#2B394C` | 可交互表面 |
| 边界 | `#334154` | 分区、输入框轮廓 |
| 正文 | `#E7EDF5` | 标题与主要内容 |
| 辅助文字 | `#A3AFBF` | 参数说明与状态摘要 |
| 强调色 | `#80A9DB` | 选择、焦点、开关、滑块 |
| 信息标签 | `#D5DFEC` / `#263447` | 浅色底与深色文字 |
| 正常录制 | `#E7A399` | REC 操作、录制状态 |
| 直播推流 | `#6DCBB7` | LIVE 操作与状态 |
| 错误 | `#ED8795` | 错误文本、停止操作 |

预览顶部来源信息条使用深色输入槽底色与浅色文字；浅色标签仅用于小型分区编号和 REC/LIVE 标记。颗粒强度为 0.025。

电平绿色和警示黄色只表达音量安全状态，不作为界面装饰色。背景形象与几何水印保持低对比。

颜色由 `Oran7RecordingWorkspace` 自有属性统一传给子组件，不读取下拉 GUI 的样式颜色。

## 后续浅色方案（待设计）

- 主体考虑雾白底板、浅灰分组与深色文字，保留深色预览画布。
- 蓝色强调色需要降低亮度，重新检验白底上的文字与焦点辨识度。
- 录制、推流维持语义色相，分别调整按钮填充、文字和状态标记。
- 单独评估颗粒、水印、阴影与禁用态，再通过 `isDark` 切换完整色板；不直接反转深色颜色。
