# QQ 音乐接入

## 当前范围

按用户最新要求，先打通界面，后续逐步接入后端。整体沿用网易云音乐的分层与交互习惯；账号、请求、曲目身份及列表数据分别管理。

已加入侧边导航「从 QQ 音乐搜索」，复用导航选中/悬停双滑块。QQ 音乐页具有搜索框、扫码登录入口、「我喜欢的音乐」「搜索结果」两个页签及刷新入口；列表继续使用 `Oran7MusicPlaylistView`。QQ 页属于音乐页面，底部播放栏和页面底部避让与本地/网易云一致。

登录浮层提供官方网页扫码流程说明、关闭/ESC、进入退出动画及窄窗口适配。未连接服务时明确显示状态，不生成假二维码、不冒充登录成功，不显示虚构歌曲，也不借用网易云的会话或列表。实际登录按钮和刷新按钮在服务未连接时禁用；搜索仍可输入并切换到结果页，提交后提示服务暂未连接。

## 界面与后端边界

`Oran7QQMusicStack` 只持有搜索输入和提示等界面状态。外部注入 `likedModel` / `searchModel`、服务连接状态、账号状态、忙状态与错误；列表模型由后续 C++ 服务持有，QML 不创建曲库副本。

页面向外发出具名意图：`searchRequested(keywords)`、`likedRefreshRequested()`、`loginRequested()`、`loginCancelled()`、`logoutRequested()`、`trackPlayRequested(model, index)`、`trackLikeRequested(track)`、`trackIntegrateRequested(track)`。这批信号尚未连接业务服务，不能据此认为实际播放、收藏或扫码已接通。

`Oran7QQMusicLoginPopup` 只呈现外部账号/登录状态，关闭正在登录的浮层时发出取消意图。当前不启动浏览器、不读写凭据、不请求 QQ 音乐接口。云端拖拽排序待策略确定后开放。

## 后续接入顺序

1. 独立官方网页登录扫码控制器：采用独立浏览器环境，验证账号成功后再提交登录；QQ/微信扫码均由官方网页提供选项。
2. 独立 QQ 音乐会话与异步网络传输：请求编号、超时、取消、账号代际及退出清理；凭据按单独 `qqmusic` 分组接入现有 DPAPI 存储，不写入公开配置。
3. 搜索和喜欢列表：统一曲目映射、分页、缓存、并发去重，收藏成员采用哈希查询；登录后预加载和进入页面刷新共用服务状态。
4. 播放地址解析、歌词、喜欢/取消喜欢、整合与重启恢复；接入统一播放队列，保留上一首/下一首和列表焦点同步。
5. 对账号切换、取消后迟到响应、网络失败、曲库量大、权限限制及网易云回归做隔离检查，真实账号由用户验收。

QQ 音乐的歌曲 MID、媒体 MID 和数字歌曲 ID 需要独立表示，不能直接套用网易云 `songId`。临时播放链接不作为持久身份，跨平台的整合列表必须携带平台标记及原始 ID。播放质量和权限以平台返回结果为准。
